# Interview Task – Lead Management CRM

Build a small **Lead Management CRM** using **Next.js with the MERN stack**.

A Lead Management CRM is a system used to manage potential customers or sales enquiries. It helps users store lead details, track lead status and progress through sales stages, and manage lead-related information from one dashboard.

Your application should include:

- Sign Up, Login and Logout
- **Sign in with Google using Google OAuth**
- Protected dashboard and routes
- Secure authentication using password hashing and JWT/session
- MongoDB user storage
- Add, View, Edit and Delete Leads
- Search, Filter, Sort and Pagination
- Lead statistics on the dashboard
- Each user must only be able to access their own leads
- Frontend and backend validation
- Loading/error states, toast notifications and delete confirmation
- Responsive UI using Tailwind CSS with shadcn/ui or Aceternity UI
- REST APIs using Node.js, Express.js and Mongoose
- Demonstrate Next.js concepts such as App Router, layouts, dynamic routes, Server/Client Components, loading/error pages, protected routes and `next/image`

Submit the completed project through a GitHub repository with clean reusable code, meaningful Git commits, `.env.example`, and a README explaining setup, MongoDB, Google OAuth configuration and how to run the application.

You may decide the project architecture, UI, database schema, authentication approach and implementation roadmap yourself. Be prepared to explain your code and technical decisions during the interview.
